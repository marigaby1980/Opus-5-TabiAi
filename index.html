Settings

Chat goes to {base}/chat/completions; web tools use the same host at /tools/*. tabitoken.com refuses browser POSTs, so this must be your Worker.
Sent as Authorization: Bearer …. With a Worker this is your APP_TOKEN. Anything hardcoded in this file is public once deployed.
Needs a TINYFISH_KEY secret on your Worker. Free; 30 searches/min, 150 URLs/min.
Runs your app in a visible frame the model drives. You can watch it happen in the Artifacts panel.
Each screenshot costs roughly 1–2k input tokens. Requires a funded balance — image requests place a larger pre-authorization hold than text. If the gateway rejects images, this turns itself off and the model falls back to inspect_dom.
Each step is a full billed request carrying the gateway's ~6.5k-token prompt floor. One message can fan out to dozens. Ceilings: depth .
